# Smart List Analyzer

A menu-driven Python project for practicing Array/Hashing and Two Pointer techniques.

## Features

- Frequency counting
- Duplicate detection
- Index lookup
- Grouping anagrams
- Hash-based difference lookup
- Opposite-end pointers
- Same-direction pointers
- Read/write pointers
- Two-array pointer technique

## Technologies Used

- Python
- Git and GitHub
- Assert-based testing

## How to Run

Run the main program:

python main.py

Run the tests:

python test_main.py

## Purpose

This project was built to practice Python programming, DSA techniques, basic testing, and version control.
